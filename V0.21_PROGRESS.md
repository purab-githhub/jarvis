# JARVIS v0.21 Progress

## Completed in this step

- Reviewed the live `main` branch and confirmed the v0.20 verification foundation is present.
- Updated `planner.py` from the stale v0.19 banner to v0.21.
- Added `planner_commands.py` as a small command-layer bridge for the existing planner features:
  - `run_week_command()` — Monday-Sunday planner
  - `run_insights_command()` — explainable priorities/conflicts
  - `run_effort_command()` — workload and capacity analysis
  - `run_conflicts_command()` — duration-aware conflicts
  - `run_planner_command()` — complete planner output

## Why this step matters

The planner functionality already existed in separate modules, but the main interactive JARVIS command loop had not yet been connected to those features. This bridge keeps that integration small and modular instead of putting planning logic directly into `main.py`.

## Next implementation step

```text
week

conflicts
planner
```

After that, add persistent user-configurable daily capacity instead of relying on the current fixed default.
